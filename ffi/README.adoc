= ffi — foreign-function surface
:toc: preamble

== Purpose

Zig is the canonical implementation language for Burble's foreign-function
kernels. Application-owned native code must not be loaded directly into the
BEAM; eligible pure numeric/buffer kernels cross the SNIF/WASM boundary.

== Contents

`zig/`:: SIMD audio/DSP/compression/neural kernel sources, tested in
`ReleaseSafe`. Proved SNIF guest artifacts are not yet shipped. The direct
Erlang NIF library and loader have been retired. See `ffi/zig/README.adoc` for
the exact readiness boundary.

== Note

SNIF supports pure numeric/buffer computation, not host I/O or BEAM resource
semantics. Missing or failed guests degrade to the BEAM reference. Firewall and
PTP device operations require a separately isolated OS service.
