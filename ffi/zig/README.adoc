= ffi/zig — Zig Coprocessor Kernels for SNIF
:toc: preamble

== Purpose

SIMD-friendly audio processing kernels intended for ReleaseSafe WebAssembly
guests executed through SNIF. Burble does not build or load an
application-owned Erlang NIF shared library.

== Key files

`build.zig`:: Zig 0.15 kernel test build. It deliberately has no Erlang NIF
header or shared-library target.

`src/abi.zig`:: Zig mirror of the Idris2 formal proofs in `verification/`. Defines `Result`, `Role`, `SignalingState` enums whose integer values MUST match the proofs in `Burble.ABI.Types` and `Burble.ABI.Permissions`. Includes runtime enforcement functions (`canEscalate`, `isValidTransition`).

`src/ffi.zig`:: Legacy C-ABI bridge utilities. It is not loaded into the BEAM;
new BEAM acceleration must use SNIF's numeric/buffer WASM ABI.

`src/coprocessor/audio.zig`:: Echo cancellation, comfort noise injection, and REMB bitrate adaptation. Echo cancel uses a real playback reference (not silence). Benchmarked at 62× faster than pure Elixir.

`src/coprocessor/dsp.zig`:: FFT (256-point, 37× speedup), convolution (27×), and spectral-gate neural denoising (6×).

`src/coprocessor/compression.zig`:: LZ4 compression for RTP payload compaction. 26 350× speedup over pure Elixir — this is the most extreme case because LZ4 is embarrassingly parallelisable with SIMD.

`src/coprocessor/ptp.zig`:: Host-I/O experiment for reading `/dev/ptp0`.
SNIF deliberately excludes host I/O, so this is not a SNIF guest and Burble
does not call it. A future isolated OS service is required.

`src/coprocessor/neural.zig`:: Spectral gating implementation used by the denoiser. Not a TFLite model — pure signal processing.

`src/coprocessor/firewall.zig`:: Packet validation helpers called from the transport layer.

== Build

[source,bash]
----
cd ffi/zig
zig build test -Doptimize=ReleaseSafe
----

Or via the top-level Justfile:

[source,bash]
----
just build     # verifies kernels and builds the server
just test-ffi  # runs the Zig test suite
just bench     # benchmark work remains provisional until SNIF guests exist
----

== How it fits into the system

```
Burble.Coprocessor.SmartBackend (Elixir)
  ├─► proved ReleaseSafe WASM guest available: SNIF sandbox
  └─► otherwise: Burble.Coprocessor.ElixirBackend (BEAM reference)
```

Until the SNIF buffer ABI and Burble guest artifacts are complete,
`SNIFBackend.available?/0` is false and the reference implementation is used.
Missing artifacts are never described as accelerated or proved.
